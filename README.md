# Simple-Java-Bank-App

A simple banking app with a Swing window, written in Java using OOP.

## Features
- PIN login with 3 tries, then the card is blocked
- Deposit and withdraw money
- Simple transaction history
- Input validation for bad amounts

## OOP concepts
- Account class keeps its data private and exposes methods
- BankGUI handles the screens and buttons, Account handles the rules

## How to run
1. Open the folder in BlueJ and click Compile
2. Right-click BankGUI > void main(String[] args)
3. Demo PIN: 1234
